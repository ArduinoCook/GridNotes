# GridNotes
Grid Notes
Notes, SQL Code and Data — Right Where You Work

Grid Notes is an Excel add-in created to make it easier to keep useful notes, SQL code, and working information together while working in Excel.

When working with spreadsheets, it's common to need somewhere to write down an explanation, remember a piece of SQL, document a calculation, record a data issue, or simply make a quick note about what you're doing.

Instead of opening Notepad, Word, or another application, Grid Notes gives you a dedicated workspace directly inside Excel.

Why I Created Grid Notes

I created Grid Notes because working with data often involves more than just the spreadsheet itself.

When analyzing or developing data, I frequently found myself needing to keep information alongside the Excel workbook:

SQL queries
Data notes
Explanations
Reminders
Troubleshooting information
Temporary calculations
Ideas and observations
Information about the data being analised

Opening another application to keep these notes was inconvenient, and notes could easily become separated from the work being done.

Grid Notes was created to solve that problem.

The idea is simple:

Keep your notes close to your data.

What Can Grid Notes Do?
📝 Keep Working Notes

Use Grid Notes as a simple workspace for recording information while working in Excel.

Your notes can be saved and retrieved the next time you use Grid Notes.

💻 Store SQL Code

The SQL Code area provides a convenient place to keep SQL statements while working with data.

You can use it for:

SELECT statements
INSERT statements
UPDATE statements
DELETE statements
JOINs
Stored procedure scripts
Queries used for testing
Temporary SQL code

This makes Grid Notes particularly useful for people who work with both Excel and SQL Server.

📊 Work With Grid Data

Grid Notes can also provide a workspace for working with tabular data.

The intention is to make it easier to move between spreadsheet data, notes and development work without constantly switching between applications.

📑 Multiple Tabs

Grid Notes uses separate tabs for different types of information.

For example:

Grid
For working with tabular data.

Notes
For general notes, explanations, reminders and documentation.

SQL Code
For SQL queries and database development.

Additional tabs can also be used as the application develops.

Your Information Is Saved

Grid Notes saves the information associated with each workspace separately.

This means your Notes, SQL Code and other information can be maintained independently rather than being mixed together.

When you return to Grid Notes, your previously saved information can be loaded again.

Clear Your Notes

Grid Notes also provides a Clear function for removing information from the currently selected workspace.

Before information is cleared, Grid Notes asks for confirmation to help prevent accidental deletion.

Who Is Grid Notes For?

Grid Notes was originally created with people who work with data in mind.

It can be useful for:

Data analysts
SQL developers
Database developers
Business intelligence developers
Excel power users
Data engineers
Students learning SQL
Anyone who regularly works with spreadsheets and data

You don't need to be a database developer to use Grid Notes, though.

If you work in Excel and often need somewhere to keep useful information, Grid Notes can help.

Why Use Grid Notes Instead of Notepad?

Notepad is excellent for simple text.

The problem is that it is separate from the application where you're actually working.

Grid Notes is designed to keep your supporting information together with your Excel workflow.

Instead of:

Excel → Notepad → SQL Server → Excel → Notepad

Grid Notes provides a central place for your notes and development information while you work in Excel.

The Philosophy Behind Grid Notes

Grid Notes was built around a straightforward idea:

Your data is important, but the information you use to understand and work with that data is important too.

A spreadsheet might contain thousands of rows of information, but often the most valuable information is the explanation behind it.

Why was this column created?

What does this calculation do?

Where did this data come from?

What SQL query produced these results?

What needs to be fixed tomorrow?

Grid Notes gives you somewhere to record those answers.

Built for Practical Use

Grid Notes isn't intended to replace Excel, SQL Server, Notepad or other development tools.

Instead, it is designed to complement them.

It provides a lightweight workspace for the information that sits between the data and the person working with it.

What's Next?

Grid Notes is an evolving project.

The application was created from a practical need and will continue to develop based on the features that are useful to people who work with Excel and data.

Future improvements may include additional workspace functionality, improved data handling, export capabilities and other tools that make working with data easier.
